1. The -y Pluralization Principle

Consonant + y vs. Vowel + y
Environment Rule Applied Correct Plural Forms Frequent Misspellings
Consonant + -y Drop -y → add -ies categories, policies, disparities, subsidies, strategies categorys, policys, disparitys
Vowel (a, e, o, u) + -y Keep -y → add -s attorneys, surveys, delays, essays, alleys attornies, survies, delaies
-quy combinations qu functions as consonant → add -ies colloquies, soliloquies colloquys, soliloquys

3. -f/-fe and -o Variations

-f → -ves vs. fixed -s

leaf → leaves, half → halves, thief → thieves.
Contrast: belief → beliefs, chief → chiefs, brief → briefs.

-o → -os vs. -oes

scenario → scenarios, ratio → ratios, portfolio → portfolios.
Contrast: veto → vetoes, embargo → embargoes.

4. Invariable Academic Plurals

Identical Singular & Plural Forms

These preserve an identical spelling in singular and plural:

  • one species → several species
  • one series → numerous series
  • one means → various means

Avoid: specie (currency), serie.
