Core Foundations

Count Nouns Separate Units

Count nouns are things we can count individually with numbers. They have both singular and plural forms.

Singular & Plural
1 chili 3 chilies
  • Use a / an for singular count nouns:
    "I have a chili." / "She ate an apple."
  • Use 'some' with plurals in affirmative (+) sentences:
    "I'd like some chilies."
  • Use 'any' in negative (-) and questions (?):
    "I don't have any chilies."
    "Do you have any chilies?"
Non-Count Nouns Mass / Whole

Non-count nouns are things we view as a whole substance or concept that cannot be easily divided and counted individually.

Form Rules
rices rice (Always singular)
  • Never use a / an:
    Say "rice", not "a rice".
  • Use 'some' in affirmative (+) sentences:
    "I ate some rice."
  • Use 'any' in negative (-) and questions (?):
    "I didn't eat any rice."
    "Did you eat any rice?"
Quick Reference Guide

Rules of Grammar at a Glance

Sentence Type Singular Count Noun Plural Count Noun Non-Count Noun
Affirmative (+) I bought a chili. I'd like some chilies. I ate some rice.
Negative (-) I don't have a chili. I don't have any chilies. I didn't eat any rice.
Question (?) Do you have a chili? Do you have any chilies? Did you eat any rice?
Important Warning Needs a / an Add -s / -es ending NO 'a/an' • NO plural -s

Milk

Non-count (some milk)

Banana / Bananas

Count (a banana / 2 bananas)

Bread

Non-count (some bread)

Potato / Potatoes

Count (a potato / potatoes)
