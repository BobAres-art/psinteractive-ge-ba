How to Use the Present Perfect Simple
Grammar Rule
have / has + Past Participle (V3)
1. Choosing have or has

• I / You / We / They + have (We have emailed the client.)
• He / She / It + has (She has checked the budget.)

2. Useful Office Words

• already: done earlier than expected (We have already sent it)
• just: done a very short time ago (He has just started)
• yet: for things not done until now (I haven't called yet)

3. Regular & Common Irregular Verbs

• Regular: work → worked, check → checked
• Irregular: send → sent, write → written, see → seen
